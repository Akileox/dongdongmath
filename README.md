# TeamDJ (DongdongMath)


## 1. 프로젝트 개요
- **목적**: 학생들에게 고화질 강의와 실시간 질문/답변 기능을 제공하여 학습 효율을 극대화.
- **주요 기능**:
    - **강의 시청**: 유튜브 기반의 플레이어, 타임스탬프 질문 기능.
    - **질문/답변**: 실시간 Q&A 보드, AI 답변 초안 생성 (Mock).
    - **관리자**: 강의 등록, 학생 CSV 일괄 등록.

## 2. 계정 생성 및 테스트 안내 (⭐️ 중요)
현재 회원가입 기능은 **관리자 승인제**(또는 관리자가 생성)를 가정하고 있으나, 
테스트를 위해 다음과 같은 방법으로 **관리자 계정**을 얻을 수 있습니다.

1.  **회원가입**: `/notices` 등에서 [로그인] 버튼 > 로그인 폼 하단(현재 숨겨짐) 또는 Supabase Auth UI를 이용해야 하지만, 
    *   현재 UI에는 "회원가입" 버튼이 없습니다. 
    *   **테스트 방법**: Supabase 대시보드 > `Authentication` 탭에서 직접 사용자(User)를 추가하세요. (초대 메일 발송)
    *   또는, `/login` 페이지 코드를 잠시 수정하여 `signUp` 기능을 노출시켜 가입할 수 있습니다.
2.  **권한 변경**: 
    *   가입 후, **Supabase Table Editor** > `profiles` 테이블로 이동합니다.
    *   방금 가입한 사용자의 `role` 컬럼 값을 `student` -> `admin`으로 변경합니다.
3.  **로그인 확인**:
    *   `/login` 페이지에서 해당 계정으로 로그인합니다.
    *   `/dashboard/admin` 페이지에 접근 가능하면 성공입니다.

## 3. 사용 가이드

### [사용자 입장] (학생)
1.  **메인 페이지 (`/`)**
    -   플랫폼 소개를 확인하고 [로그인] 버튼을 클릭합니다.
2.  **로그인 (`/login`)**
    -   학원에서 부여받은 이메일/비밀번호로 로그인합니다.
3.  **대시보드 (`/dashboard`)**
    -   나에게 배정된 강의 목록을 확인하고 [학습 시작하기]를 클릭합니다.
4.  **강의실 (`/dashboard/lectures/[id]`)**
    -   강의를 시청하다가 모르는 부분이 생기면 영상 우측 상단의 **[...에 질문하기]** 버튼을 누릅니다.
    -   타임스탬프가 자동 기록되며, 질문 내용을 입력하여 등록합니다.
    -   우측 사이드바에서 내 질문과 답변 상태를 실시간으로 확인합니다.

### [관리자 입장] (선생님/조교)
1.  **로그인**
    -   관리자 계정으로 로그인 시 관리자 권한이 자동 부여됩니다.
2.  **관리자 페이지 (`/dashboard/admin`)**
    -   **강의 추가**: 유튜브 링크를 복사하여 강의를 등록합니다.
    -   **학생 등록**: `.csv` 파일을 업로드하여 학생 계정을 일괄 생성합니다. (형식: `email,name,phone`)
3.  **답변 달기**
    -   학생이 질문을 등록하면 질문 목록에 [답변하기] 버튼이 표시됩니다.
    -   클릭 시 AI가 추천하는 답변 초안이 미리 입력되어 있습니다.
    -   내용을 검토/수정 후 [등록]하면 학생에게 즉시 전송됩니다.

## 3. 기술 스택
-   **Frontend**: Next.js 14+, Tailwind CSS (Light Simple Theme)
-   **Backend**: Supabase (Auth, DB, Realtime)
-   **AI**: Gemini (Mock Integration)
